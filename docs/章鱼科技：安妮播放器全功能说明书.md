## 第一章 产品概述

安妮播放器融合版V3 是一款面向 Windows 10/11 的桌面级 HiFi 音乐播放器，由无敌章鱼哥独立开发。它将三条技术路线融为一体：

1. **章鱼自研音频引擎 AnnieEngine**——独立 .NET 8 进程，WASAPI 独占 / ASIO 专业输出，Bit-perfect 播放；
2. **Mineradio 3D 可视化视觉栈**——Three.js 粒子舞台、节拍驱动相机、歌词星河；
3. **洛雪音乐流媒体生态**——五大平台在线搜索、自定义音源沙箱、四平台歌词解密、音质校验下载。

它不是多个软件的简单拼装：所有模块运行在同一 Electron 进程内，共享同一播放队列、同一曲库、同一套播放状态，主题切换播放不中断。

### 版本血缘

```
V3 稳定版 → EXP 7.28(性能工程) → Plus(界面打磨) → PlusPro(音质专业化)
        → Win10版(3D可视化舞台) → SVLX 融合版V3(洛雪生态 + AM主题 + SACD)
```

## 第二章 章鱼自研音频引擎 AnnieEngine（核心）

AnnieEngine 是本播放器的灵魂——一个完全由章鱼科技自研的独立音频引擎，以 sidecar 子进程形式运行（`AnnieEngine.exe`），与界面进程通过 stdio 行分隔 JSON-RPC 通信。

### 2.1 为什么用独立进程架构

- **音质隔离**：音频解码与渲染不经过 Electron/Chromium 的音频栈，避免浏览器重采样与混音器染指；
- **崩溃守护**：引擎意外退出时，主进程指数退避自动重启并恢复播放位置，用户无感知；
- **职责清晰**：界面卡顿时音频线程不受任何影响，播放永不撕裂。

### 2.2 专业级输出链路

| 输出模式 | 说明 |
|---|---|
| **WASAPI 独占** | 绕过 Windows 混音器，采样率位直通，Bit-perfect |
| **WASAPI 共享** | 兼容性模式，与其他应用共存 |
| **ASIO** | 专业声卡/解码耳放低延迟通道 |

- **DSD 原生 / DoP 直通**：DSD 码流不解码为 PCM，直接送达支持 DSD 的 DAC；
- **Bit-perfect 状态灯**：实时指示当前链路是否位完美（重采样/EQ/响度介入会明确标示）；
- **缓冲/预载可配置**：内存缓冲与预读策略可按机器性能调节。

### 2.3 DSP 数字信号处理

- **15 段参量均衡器**：32Hz ~ 16kHz，RBJ biquad 滤波器链，±12dB 增益，**热更新不断流**——拖动 EQ 时音乐不中断；
- **EBU R128 响度归一**：曲目间响度自动拉平，切歌不再忽大忽小；
- **防削波链路**：前级增益补偿 + tanh 软限幅，大动态不失真；
- **Crossfade 交叉淡入**：切歌时前后曲目平滑交叠。

### 2.4 解码能力

- 本地全格式：FLAC / APE / WavPack / TAK / DSF / DFF / WAV / AIFF / MP3 / AAC / OGG / OPUS 等；
- **SACD ISO 分轨**（v1.2.0 新增）：内置 sacd_extract 工具链，整张 SACD 镜像自动探测分轨、以虚拟曲目入列；
- **CUE 分轨**：整轨镜像 + CUE 表自动拆分为虚拟曲目，精确到秒级起止；
- **流媒体拉流解码**：HTTP/HTTPS 流直接进引擎，配合请求头注入解决平台防盗链；
- 引擎自带 ffmpeg / ffprobe 工具链，为可视化分析、格式探测、频谱计算提供支撑。

## 第三章 三大并列主题

主题随时切换（设置 → 外观，或命令面板 Ctrl+K），**播放队列与进度完全连续**。

### 3.1 粒子舞台（默认）

- Three.js 3D 场景：封面粒子、骷髅头粒子（顶点抽稀加速）、歌词星河、声波地形；
- **13 个视觉预设**：含「音域回响」（Wallpaper Engine 壁纸桥接）、月蚀圣环、雨幕霓虹、折光蝶群、深海绽放等；
- music-tempo 节拍检测驱动相机运镜与粒子律动；
- 舞台休眠：切到其他主题后 GPU 渲染完全停止，仅保留 4fps 心跳。

### 3.2 FB2K（仿 foobar2000）

- 效率优先的列表界面，暗色模式，虚拟滚动支撑 5000+ 曲目 60fps；
- 平铺文件夹导航、平铺/列表双模式、跨主题播放位置自动定位。

### 3.3 Apple Music 主题（v1.2.0 全新）

- **磨砂玻璃质感**：顶栏/侧栏/歌词面板高斯模糊 + 饱和提升（Liquid Glass 风格）；
- **封面氛围背景**：当前封面放大 90px 高斯模糊铺满全窗，随切歌渐变；
- **AM 风格歌词**：大字号逐行高亮、相邻行半亮、远处行微模糊，点击任意行跳转；
- **亮/暗双主题**：一键切换，独立记忆；
- AM Windows 式顶栏：传输控制、迷你封面、当前时间/剩余时间、**音质徽标**（如 FLAC · 24bit · 96kHz）；
- 侧栏资料库：歌曲 / 专辑（封面网格）/ 文件夹 / 喜爱，外加内嵌**洛雪在线搜索**——五大平台切换、音质选择、单击即播、整列自动续播；
- 专辑级封面共享：每张专辑只解析一次封面，千行列表滚动依然顺滑。

## 第四章 本地曲库

- **Worker 线程扫描**：曲库扫描与标签解析全部在独立线程执行，崩溃自动重建降级，绝不卡界面；
- **metaCache 持久化**：标签解析结果落盘缓存，全库解析只有一次成本；
- **全库搜索**：AM 主题输入关键词即后台分块补全标签，歌名/艺人/专辑全能搜；
- **假无损批量检测**：Goertzel 频谱算法识别"假无损"（低码率转封装的伪 FLAC）；
- **播放统计**：播放次数、跳播率、最近播放，构成"重起炉灶"智能歌单的数据基础。

## 第五章 自建播放列表（v1.2.0 新增）

- 新建 / 重命名（点击名称即改）/ 删除 / 加歌（行内 ⊕ 按钮或右键）/ 移除；
- 数据持久化于 library.json，三个主题共享同一份歌单；
- 歌单详情页：封面头图、曲目数统计、播放 / 随机播放按钮。

## 第六章 流媒体（洛雪深度融合）

- **五大平台**：酷狗 / 酷我 / 咪咕 / QQ / 网易，分页加载；
- **自定义音源**：兼容洛雪 2.x 音源脚本（.js 导入，vm 沙箱隔离），多音源自动回退；
- **音质分级**：Hi-Res 24bit / 无损 FLAC / 极高 320K / 标准 128K，播放与下载共用；
- **格式校验**：探测 URL 真实格式，音源"标 FLAC 给 MP3"会被识别、降级并明确提示；
- **流式下载**：自定义目录、实时进度；
- **歌词解密**：酷狗 KRC（XOR+zlib）、酷我 lrcx（yeelion+gb18030）、QQ QRC（原生模块）、咪咕 mrc。

## 第七章 其他特性

- **桌面歌词**：独立无边框悬浮窗，可调字体/颜色/锁定；
- **迷你模式**：N 键 Now Playing 全屏；迷你条只保留核心控制；
- **命令面板**：Ctrl+K 全局唤起，搜索功能与命令；
- **便携模式**：程序目录下存在 `portable/` 文件夹时，所有数据写入该目录，U 盘带走即用；
- **系统托盘**：最小化到托盘，后台继续播放；
- **诊断包导出**：一键打包日志与配置，便于反馈问题。
